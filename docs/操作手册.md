# 操作手册

## 先确认三针接线

本项目用于 V4.2 总控板和众灵 ZP10S。使用原装、针序一致的三针线。断电后按板端针号核对 `J_SERVO`。

| `J_SERVO` 针号 | 用途 |
|---|---|
| 1 | `PB6` 经单向缓冲器输出的 5 V 逻辑信号 |
| 2 | 舵机 5 V 电源 |
| 3 | GND |

原理图和针号见[项目总控板针脚表](https://github.com/WuWingKit/tree-whitewashing-robot/blob/main/hardware/pcb/robot_electronics_v4_2_four_layer/PINOUT.csv#L404-L421)。该插口无回读路径。保持舵机与夹爪脱开，底盘和滑台动力断开。舵机采用总控板已核对的 5 V 支路供电。

## 第一次打开电脑窗口

在项目目录的 PowerShell 中运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

按[构建和装载](构建和装载.md)把对应的 ESP32 应用装好，再把 STM32 点动程序加载到 RAM。双击项目根目录的 `打开按住点动.cmd`。首次配对在 ESP32 的 USB 串口启动日志里查 `TreeServoBench pairing PIN`，将该次启动的六位码填入窗口。已保存配对的同一台电脑可以留空，直接点击「连接蓝牙」。

## 用鼠标控制

- **按住逆时针／顺时针**让舵机连续小步移动。方向从输出轴正面观察。
- **松开、移出按钮、按 Esc 或点停止**会停止续发。收到停止后，舵机仍可能完成已收到的一小步。
- 试验保护范围是 `600–2400` 个位置单位。它用于空载限制，不能当作夹爪机械限位。
- 若窗口显示等待 STM32，检查 STM32 是否有电，以及是否已重新加载 RAM 程序。若找不到设备，先确认没有另一台电脑或旧窗口正在连接。

## USB 什么时候能拔

鼠标指令通过 BLE 发送。USB 用于加载 STM32 程序、更新 ESP32 和观察串口日志。如果 USB 同时给主控供电，拔线会造成主控掉电，RAM 程序也会丢失。只有总控板和舵机的独立供电已验证，并且 STM32 在拔 USB 时不会重启，才可在这一轮测试中脱离电脑 USB。若原车 Flash 中仍有自动动作测试固件，重启后可能执行旧固件行为，装回夹爪前应采用专用的手动固件并验证限位和上电行为。\n
