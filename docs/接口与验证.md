# 接口与验证

```mermaid
flowchart LR
    Windows[Windows 点动窗口] -->|BLE 有认证的 GATT 写入| ESP[ESP32-S3]
    ESP <-->|UART 115200 8N1| STM[STM32F407]
    STM -->|PB6 / USART1 TX 经三针口| Servo[ZP10S]
```

## 关键接口

- ESP32-S3 `GPIO17 TX → STM32 PA3 RX`，STM32 `PA2 TX → ESP32-S3 GPIO18 RX`，板间共地。
- 窗口通过 BLE 发送 `CW`、`CCW` 或 `STOP`。按住时约 `80 ms` 续发。STM32 若约 `350 ms` 未收到有效续发就取消后续小步。即使 BLE 状态读取超时，控制超时仍由 STM32 独立执行。
- STM32 发送 `#255PxxxxT0100!` 位置命令，`255` 是单舵机测试时使用的广播地址，`xxxx` 是目标位置单位，`0100` 是 `100 ms` 的动作时间。`CW` 减少目标值，`CCW` 增加目标值。限幅 `600–2400`，每步 `20`。这套方向映射来自本次实车空载反馈。

## 验证依据

| 验证 | 结果 |
|---|---|
| 原三针空载验证 ZP10S | 只用 `115200` 串口发 `1500 → 1200 → 1800 → 1500`。现场确认舵机向两侧摆动并回中。 |
| 早期 PWM 排查 | 在 STM32 `PB6` 读到约 `20 ms` 周期，ZP10S 空载对已试 PWM 值未响应。后续使用手册的串口位置协议。 |
| Windows 重连 | 实车首次配对成功，之后两次留空 PIN 重连，均通过认证后的 `STOP` 写入及 `READY` 状态读回。 |
| 点动与停止 | 固件指令测试覆盖启动无动作、顺逆方向、按住续发、松手停止、失联保护和试验限幅。 |
