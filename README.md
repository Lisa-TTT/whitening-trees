# ZP10S 舵机蓝牙点动

树干涂白机器人夹爪的空载控制项目。Windows 电脑通过 BLE 连接 ESP32-S3，ESP32-S3 把指令转给 V4.2 总控板的 STM32F407。STM32 从 `J_SERVO` 向众灵 ZP10S 发送 `115200` 单线串口位置指令。

## 已经实现

- **按住顺时针／逆时针**，每 100 ms 小步移动一次。松开鼠标、移出按钮或点「停止」，会取消剩余的小步。
- Windows 和 ESP32 保留已认证的配对，同一台电脑重连时可以留空 PIN。
- 电脑停止续发或蓝牙断开时，STM32 自动停发。停止指令到达前的 BLE 延迟、最后一段的完成时间都会影响实际停位。

## 从哪里开始

1. 按[操作手册](docs/操作手册.md)确认三针接线，先保持舵机与夹爪脱开，断开滑台、底盘动力。
2. 配置桌面端依赖，加载 STM32 RAM 程序，打开 `打开按住点动.cmd`。
3. 在控制窗口连接蓝牙，从输出轴正面观察顺逆时针，在空载下验证松手停止。

| 目录 | 内容 |
|---|---|
| `desktop/` | Windows 点动界面和 BLE 配对、重连 |
| `firmware/esp32/` | ESP32-S3 蓝牙转发 |
| `firmware/stm32/` | STM32F407 串口点动、限幅和续发超时 |
| `firmware/common/` | 板间帧协议和 CRC |
| `scripts/` | STM32 构建与 USB RAM 加载 |
| `images/` | 从本仓库源码构建的试验镜像及 SHA-256 |

**当前是空载标定版。** STM32 程序运行在 RAM，掉电或复位后要重新加载。舵机没有位置回读，窗口只显示控制指令状态。机构的张开方向、80° 对应的实际位置及安全开闭限位仍需装机前标定。滑台和整车控制各自独立。\n
